## Known issues (read before enabling everything)

### Visual quality — terrain

- Terrain may present as **smooth, RGB-tinted slabs** rather than crisp biome detail. Biome color wiring improved in #208 but is still rough around save-load and partial tile failures.

### Voxel actors — flashing / eyebleed

- **Voxel actor rendering can flash badly** — broken LOD handoff / impostor slop, not a finished look.
- **Workaround:** open the **WSM tab → Extended settings** (top row). **Voxel Actors** is the **3rd toggle from the left**, between **Cam** and **Profiler dump**. Flip it **off** to stop voxel render attempts while keeping the rest of the mod loaded.

### GPU / platform

- Recent GPU/compute work is **primarily validated on D3D11 (Windows)**.
- **macOS / Metal and Linux / Vulkan** may crash or behave worse — unoptimized paths and API translation gaps are still open.
- If the mod icon is **red**, hardware lacks compute-shader / GPU-instancing support (upstream gate preserved).

## Install

1. Extract `WorldSphereMod3D-2.0.0-beta.7.zip`
2. Copy the folder contents into:

   `<WorldBox>/worldbox_Data/StreamingAssets/Mods/WorldSphereMod/`

   Default Steam path:

   `C:\Program Files (x86)\Steam\steamapps\common\worldbox\worldbox_Data\StreamingAssets\Mods\WorldSphereMod\`

3. Launch WorldBox; enable **WorldSphereMod3D** in NeoModLoader
4. In-game: **WSM tab → 3D Phases** to toggle features; see workaround above if voxels flash

Or from a dev checkout:

```powershell
cd E:\Dev\WorldSphereMod
pwsh Tools/wsm3d.ps1 install
```
